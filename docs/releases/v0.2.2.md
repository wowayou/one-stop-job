# job-one-stop v0.2.2

v0.2.2 是自动驾驶与三级求职面版本的正式可安装发行版，修复桌面安装包流水线的两个跨环境问题：CI 未安装 Tauri CLI，以及 Tauri 构建命令从 `src-tauri` 目录解析错误的前端路径。

功能内容与 v0.2.1 相同：自动驾驶只在本地完成搜集、去重、分类、评分和材料准备；投递与招聘者沟通仍需用户确认。

## 安全边界

- 不自动投递。
- 不自动向招聘者发送消息。
- 不绕过验证码、风控页或平台限制。

## 升级说明

- 默认仍为“手动 + 核心”，升级后不会自行启动自动化。
- 无数据库迁移；原有岗位状态和个人看板不会被自动改变。

## 安装说明

- Windows：下载 `.msi` 或 `.exe`，双击安装。
- macOS：下载 `.dmg`，拖入 Applications；首次打开可右键选择“打开”。
- Linux：下载 `.AppImage`，添加执行权限后运行。

本版本安装包未做商业代码签名。操作系统提示未知开发者时，请按系统流程确认后继续。
