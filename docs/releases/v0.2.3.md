# job-one-stop v0.2.3

这是 v0.2.2 的安全修复版，重点解决桌面版误连已有本地后端的问题。

## 本版重点

- Tauri 桌面版启动后端时自动选择空闲回环端口，不再固定占用 `8000`。
- 前端通过 Tauri IPC 获取本次启动的实际后端端口。
- 桌面版不会再误连已运行的开发服务器、单进程服务或 Docker 后端。
- 发布流水线增加凭据门禁，阻断 `.env`、`config.yaml`、数据库和运行时密钥进入安装包。

## 安全边界

- 不自动投递。
- 不自动向招聘者发送消息。
- 不绕过验证码、风控页或平台限制。
- AI Key 只从本机 `.env` 或环境变量读取，不进入前端构建产物和 Tauri 资源。

## 升级说明

- 默认仍为“手动 + 核心”。
- 无数据库迁移；原有岗位状态和个人看板不会被自动改变。
- 如果此前运行过 v0.2.2，建议升级后停止旧后端再启动桌面版。

## 安装说明

- Windows：下载 `.msi` 或 `.exe`，双击安装。
- macOS：下载对应架构 `.dmg`，拖入 Applications；首次打开可右键选择“打开”。
- Linux：下载 `.AppImage`，添加执行权限后运行；也可使用 `.deb` 或 `.rpm`。

本版本安装包未做商业代码签名。操作系统提示未知开发者时，请按系统流程确认后继续。
