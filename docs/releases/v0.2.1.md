# job-one-stop v0.2.1

v0.2.1 是自动驾驶与三级求职面版本的正式可安装发行版。功能内容与 v0.2.0 相同，并修复 GitHub Actions 未安装 Tauri CLI、导致四平台安装包无法生成的问题。

## 本版重点

- 自动驾驶每日扫描，首页和设置页均可开启、停止或立即扫描。
- 核心 / 相邻 / 探索三级求职面，按岗位族生成搜索计划并重评候选。
- 候选评分闸门、硬条件拦截和每日待确认上限，过滤结果保留审计摘要。
- 自动生成本地材料包：简历版本建议、投递理由、风险问题。
- 候选卡展示岗位族、能力重合、必要条件缺口和可补齐差距。
- 新增首次使用检查、产品导览、侧栏使用指南和完整操作手册。
- 写入个人看板时附带 JD 链接，并修复链接数字被误判为日期的问题。

## 安全边界

- 不自动投递。
- 不自动向招聘者发送消息。
- 不绕过验证码、风控页或平台限制。

## 升级说明

- 默认仍为“手动 + 核心”，升级后不会自行启动自动化。
- 无数据库迁移；原有岗位状态和个人看板不会被自动改变。

## 安装说明

- Windows：下载 `.msi` 或 `.exe`，双击安装。
- macOS：下载 `.dmg`，拖入 Applications；首次打开可右键选择“打开”。
- Linux：下载 `.AppImage`，添加执行权限后运行。

本版本安装包未做商业代码签名。操作系统提示未知开发者时，请按系统流程确认后继续。
